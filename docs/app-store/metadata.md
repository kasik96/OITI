## Description
Open Infrared Thermal Imager turns a USB‑C iPad (and Mac) into a full thermal camera when paired
with a compatible 256×192 USB‑C UVC infrared camera.

• Live radiometric thermal view over USB‑C
• Real per‑pixel temperatures: min, max, centre, and tap‑to‑add spot readings
• Emissivity and reflected‑temperature correction
• 7 colour palettes: Iron, Rainbow, White/Black hot, Lava, Arctic, Medical
• Enhanced mode (auto contrast + noise reduction) or Linear mode (colour = temperature)
• Auto‑rotation, manual rotate lock and flip
• Save a PNG snapshot and a CSV of every pixel's temperature, straight to Files

Everything runs on‑device. No account, no analytics, no ads, no network access.

Requires a compatible USB‑C UVC thermal camera (256×192). The camera is sold separately and is
not affiliated with this app.
